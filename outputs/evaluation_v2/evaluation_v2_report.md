## v0.4 missed-event analysis

At K=500, v0.4 misses **86** of 96 event flags. The CSV lists each missed package, both model ranks/scores, event type, and derived product. Differences are descriptive; causes are not identified without feature-level historical records.

## Limitations and next experiment

- Product NDC derivation is a structural approximation because the dashboard file omits FDA `product_id`.
- The published cohort has no pre-period feature columns, so heuristic baseline performance cannot be estimated from this artifact alone.
- The bootstrap holds observed ranks fixed and estimates cluster sampling uncertainty; it does not remove development-set inspection or temporal-source risks.
- The next phase should use frozen source snapshots to add pre-period baselines and exact FDA product mappings, then evaluate a genuinely untouched temporal period.
