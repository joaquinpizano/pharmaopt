# PharmaOpt

PharmaOpt is a pharmaceutical supply-chain analytics project focused on integrating and analyzing public drug shortage, NDC, and recall datasets.

## Project Goals

- Combine pharmaceutical shortage, product, package, and recall data
- Improve matching between datasets using NDC identifiers
- Analyze patterns related to drug shortages and recalls
- Build a structured MySQL database for further analysis
- Use Python and SQL to clean, transform, and analyze large healthcare datasets

## Current Results

- 1,601 drug shortage records analyzed
- 1,570 unique shortage NDCs identified
- 1,393 shortage NDCs successfully matched
- 88.7% NDC match rate
- 17,975 recall records analyzed
- 40,316 recall-package relationships identified
- 435 NDCs found in both shortage and recall datasets

## Tools Used

- Python
- Pandas
- MySQL
- Jupyter Notebook
- Excel
- Public FDA / pharmaceutical datasets

This project is currently in development. Additional modeling, analysis, and visualization components are being added.
