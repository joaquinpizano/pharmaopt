\# PharmaOpt



PharmaOpt is a pharmaceutical supply-chain analytics project that combines public FDA and CMS data to analyze drug shortages, recalls, product information, and utilization patterns.



\## Project Goals



\- Integrate FDA drug shortage, NDC, and recall datasets

\- Build a structured MySQL database for pharmaceutical analysis

\- Match NDC identifiers across multiple datasets

\- Analyze drug shortages, recalls, and manufacturer patterns

\- Incorporate Medicare Part D utilization data

\- Develop supply-risk and business-impact analytics



\## Current Results



\- 138,217 drug product records

\- 256,383 drug package records

\- 1,601 shortage events

\- 17,975 recall events

\- 25,577 recall-package relationships

\- 88.7% shortage NDC match rate

\- 76.92% recall-package match rate
